# Decisiones de arquitectura y producto (ADR)

Cada archivo guarda algo que el dueño del producto **decidió no hacer** (o hacer de cierta forma), con su contexto y su motivo, para que nadie lo vuelva a proponer sin saber por qué se descartó. Lo pendiente vive en [`../tech-debt-and-future-work.md`](../tech-debt-and-future-work.md).

Formato: `NNNN-titulo-corto.md` con Estado, Contexto, Decisión, Motivo y Consecuencias. Los números no se reutilizan. Si una decisión cambia, se agrega un ADR nuevo que reemplaza al anterior y el viejo pasa a «Reemplazada por NNNN». Si el dueño no dio un motivo, se escribe tal cual; nunca se inventa.

Aún no hay decisiones registradas en este repo. Las de srtomy-api están en su propio `docs/adr/`.
